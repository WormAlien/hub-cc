# Список SOCKS/HTTP-прокси для фермы: один адрес на строку.
#
# Форматы:
#   socks5://host:port
#   socks5://user:pass@host:port
#   http://host:port
#
# 🪤 Этот файл (socks-alive.txt) ПЕРЕЗАПИСЫВАЕТСЯ кнопкой «Авторега» перед
# каждым запуском: хаб сам скрапит свежие адреса под uncensoredlabs.dev и
# кладёт их сюда. Держать здесь что-то ценное бессмысленно.
#
# Файл нужен как заготовка, чтобы прогон не упал на «нет списка прокси»,
# если скрап в этот момент не поднялся. Прокси живут минуты — статичный
# список почти всегда мёртв, это нормальный фолбэк, а не рабочий набор.
#
# Лимит площадки: 5 регистраций на IP в 24 часа. Скрипт соблюдает его сам
# (--per-ip), прокси нужен по одному на аккаунт.
