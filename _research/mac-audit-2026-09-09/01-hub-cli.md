### [COSMETIC] `статус` на маке печатает висячее двоеточие: `папка: · /путь`
- **Где:** `hub.js:652-655`
- **Что происходит на маке:** ветка прав на не-Windows отдаёт `dim('папка:')`, а следующая строка клеит к нему разделитель:
  ```js
  const rights = L.IS_WIN
      ? (L.isElevated() ? `${dim('права:')} ${yellow('администратор')}` : dim('права: обычные'))
      : dim('папка:');
  line(`  ${rights}${dim(' · ' + L.ROOT)}`);
  ```
  На Windows выходит `права: обычные · D:\...`, на маке — `папка: · /Users/...`: точка-разделитель повисает между подписью и значением, которые она должна разделять.
- **Почему:** `' · '` в строке ниже рассчитан на то, что слева стоит законченная пара «подпись + значение». В darwin-ветке подпись сама стала подписью к пути.
- **Фикс:** в `hub.js:652-655` заменить на
  ```js
  const rights = L.IS_WIN
      ? (L.isElevated() ? `${dim('права:')} ${yellow('администратор')}` : dim('права: обычные'))
      : null;
  line(`  ${rights ? rights + dim(' · ') : ''}${dim('папка: ' + L.ROOT)}`);
  ```
- **Уверенность:** CONFIRMED

### [DEGRADED] `internal/menu.js`: модель ширины символов недосчитывает эмодзи — колонка `│` в менеджере сессий пляшет
- **Где:** `internal/menu.js:1161-1165` (`visW`), `:1167` (`padTo`), `:1171-1202` (`fitW`), потребитель — `:1361-1367`
- **Что происходит на маке:** ширина считается одним правилом:
  ```js
  const visW = str => [...stripAnsi(str)].reduce((n, ch) => {
      const cp = ch.codePointAt(0);
      return n + (cp >= 0x1F000 ? 2 : 1);      // emoji (U+1F000+) считаем за 2, остальное за 1
  }, 0);
  ```
  Всё, что ниже U+1F000, объявлено узким. Но символы статуса в таблице — из диапазона Dingbats/Misc, и у них `East_Asian_Width = Wide`, то есть в терминале они занимают **две** клетки:
  ```
  "✅" U+2705  visW=1  реально 2      "⏳" U+23F3  visW=1  реально 2
  "❌" U+274C  visW=1  реально 2      "⚡" U+26A1  visW=1  реально 2
  "🇺🇸" флаг    visW=4  реально 2
  ```
  `fitW(left, LEFT_WIDTH)` (`menu.js:1364,1366`) добивает левую колонку до `LEFT_WIDTH` **по этой заниженной мерке**, поэтому строка со значком физически шире на 1 клетку. Разделитель `│` встаёт на разную колонку у строк со значком и без — таблица выглядит рваной. Значки есть в каждой строке сессии (`:1220`), в заголовках секций (`:1256`, `:1263`), в шапке `⚡ Менеджер сессий` (`:1331`) и в маркере загрузки `⏳` (`:1237`).

На старом Windows-conhost глифа нет, символ занимает одну клетку, и расчёт случайно совпадал с реальностью. То есть на маке дефект гарантирован, на Windows — зависит от терминала. Автор о риске знал: комментарий на `menu.js:1133` «Используем BMP-символы (1-wide) — эмодзи рендерятся непредсказуемо», но правило применено к подписям действий и не применено к значкам таблицы.
- **Фикс:** дополнить `visW` (и зеркальную арифметику в `fitW:1192`) списком Wide-символов вне плоскости эмодзи:
