## Почему шов такой маленький

Канон [[ADDING-A-GATEWAY]] раскидывает новую вкладку по ~30 точкам реестров. Здесь этого
не нужно: MEDIA — не шлюз, своих реестров у неё нет, и она повторяет приём вкладки

7 строк — тот же порядок и тут.

## 1. `routing/transparent-proxy.js` — одна строка

В начало лестницы маршрутов (рядом с остальными `if (req.method === …)`, до общего 404):

```js
if (require('./lib/media-routes').handle(req, res)) return;
```

Модуль сам решает, его ли это запрос: берёт всё под `/__media/api/`, на чужие пути
возвращает `false`. Регресс это стережёт отдельной проверкой («чужой префикс модуль не
перехватывает»).

## 2. `routing/proxy-dashboard.html` — шесть вставок

### 2.1 Стиль, рядом со строкой `<link rel="stylesheet" href="/vendor/models-tab.css">`

```html
<link rel="stylesheet" href="/vendor/media-tab.css">
```

### 2.2 Кнопка в сайдбаре

Ставить **на место удаляемых** «Картинки API» и «Video API» (см. § 3):

```html
<button class="nav-btn group w-full text-left px-3 py-2 rounded-md text-sm flex items-center gap-2.5 text-muted hover:text-ink hover:bg-elevated transition" data-tab="media">
  <span class="text-base">🎨</span>
  <span class="flex-1">MEDIA</span>
  <span class="text-[10px] font-mono text-faint" id="nav-count-media">—</span>
</button>
```

### 2.3 Панель — пустой скелет, наполняет JS

```html
<div data-tab-content="media">
  <div id="media-root"></div>
</div>
```

### 2.4 Ленивая инициализация — рядом с `showTab()`

```js
if (name === 'media' && !state.loaded.media) { state.loaded.media = true; if (typeof MEDIA !== 'undefined') MEDIA.load(); }
```

### 2.5 Реестр обновления

```js
case 'media':         if (typeof MEDIA !== 'undefined') MEDIA.load(true); break;
```

и в списке периодического обновления:

```js
{ tab: 'media',       fn: () => (typeof MEDIA !== 'undefined') && MEDIA.load(), mark: 'media' },
```

### 2.6 Скрипт — в конец `<body>`, рядом с `<script src="/vendor/models-tab.js">`

```html
<script src="/vendor/media-tab.js"></script>
```

🪤 **Гвард `typeof MEDIA !== 'undefined'` обязателен во всех трёх местах.** Скрипт
подключён в конце body, а тик обновления может прийти раньше — без гварда получим
`MEDIA is not defined` на вкладке, которую даже не открывали. Тем же гвардом защищена
вкладка «Модели» (`proxy-dashboard.html:26336`).

### 2.7 Белый список видимых вкладок — 🪤 точка, которую легко забыть

```js
const DEFAULT_TABS_VISIBLE = [..., 'custom', 'media', 'plugins', ...];
```

Без этого кнопка **есть в DOM, но с классом `hidden`** и на неё физически нельзя нажать.
Комментарий в коде предупреждает прямо: «Новые вкладки, добавленные в nav позже, по
умолчанию тоже скрыты (их нет в whitelist)» — но при вставке это всё равно пропускается,
потому что разметка кнопки выглядит правильной. Поймано на живой проверке: Playwright
упёрся в «element is not visible».

⚠️ **У кого уже сохранён свой порядок вкладок, дефолт не применится** — конфиг лежит в
`localStorage` (`dashboard-tabs-config-v1`). Там MEDIA включается глазком в «Настроить
вкладки», одним кликом.

## 3. Что удалено

Обе вкладки — **хранилища ключей без единой строки генерации**; у «Картинки API» в
подзаголовке так и написано: «Обёртки под провайдеров — потом».

| Что | Где (строки на 2026-09-10) |
|---|---|
| Кнопка «Video API» | `proxy-dashboard.html:616` |
| Кнопка «Картинки API» | `proxy-dashboard.html:621` |
| Панель video | `proxy-dashboard.html:5397` |
| Панель image | `proxy-dashboard.html:5467` |
| Ленивая инициализация | `:8509` (`loadVideoKeys`), `:8516` (`loadImageKeys`) |
| Регистрация в обновлении | `:26184`, `:26185`, `:26259`, `:26260` |
| Функции `loadVideoKeys` / `vidShowAdd` / `loadImageKeys` / `imgShowAdd` и их соседи | по имени |

⚠️ **Номера строк протухнут**, как только параллельная сессия допишет WisdomSatan. Искать
по `data-tab="video"`, `data-tab="image"`, `data-tab-content="video"`, `data-tab-content="image"`.

🪤 **Перед сносом забрать два ключа.** `routing/video-keys.json` держит записи `fal` и
`kling` (`image-keys.json` пуст). Оба провайдера не OpenAI-совместимые и в MEDIA не
поедут — решение владельца: перенести инертными записями. Файлы не удалять.
